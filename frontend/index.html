ESP32 Hardware Specification & Connection Info

Microcontroller: ESP32 WROOM-32 DevKit
Sensor: DHT11 Temperature & Humidity Sensor (Single-bus digital protocol)
Default Data Pin: GPIO 4 (with internal or 4.7kΩ-10kΩ pull-up resistor)
Communication Protocol: Wi-Fi 802.11 b/g/n, HTTP POST REST (/api/readings)
Payload Format: {"temperature": 25.4, "humidity": 45.0, "source": "HARDWARE"}
