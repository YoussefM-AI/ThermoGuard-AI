ESP32 Hardware Node Setup

Flash and configure your physical microcontroller node

How to connect your physical ESP32 to this dashboard:

  1. Open Arduino IDE: Open esp32/cabinet_sensor.ino in Arduino IDE or VS Code with PlatformIO.
  2. Configure Wi-Fi Credentials: Update WIFI_SSID and WIFI_PASSWORD with your local 2.4 GHz network credentials.
  3. Set Ingestion Endpoint: Enter your host computer's local IP address or cloud URL:
    * Set USE_CLOUD_ENDPOINT = false for local LAN prototyping or true when deploying to Render / Railway.
  4. Upload Firmware: Select ESP32 Dev Module, connect via USB, and click Upload. The onboard LED will confirm connection.

Hardware Pinout & Wiring

Physical ESP32 node wiring specification

Component Sensor Model Sensor Pin ESP32 GPIO Connection Voltage
Cabinet Sensor DHT11 VCC (+) 3V3 (3.3V Power) 3.3V DC
Cabinet Sensor DHT11 DATA (Out) GPIO 4 (Digital I/O) 3.3V Logic
Cabinet Sensor DHT11 GND (-) GND (Ground) 0V Ref
Pull-Up Resistor Note: If using a 3-pin DHT11 module with a small PCB, the pull-up resistor is already onboard. If using a bare 4-pin DHT11 sensor, place a 10kΩ resistor between VCC (3.3V) and DATA (GPIO 4), and leave pin 3 unconnected.

Hybrid IoT + Cloud Architecture

Run locally or deploy to cloud so PC can remain powered off

ThermoGuard AI is packaged for cloud hosting (Render, Railway, Fly.io, or Docker container). When deployed to the cloud, set USE_CLOUD_ENDPOINT = true in the ESP32 firmware, and your IoT cabinet node will stream telemetry 24/7 without requiring your personal computer to stay on.
